# 카드뉴스 기획서 — LCK 2026 서머 관전포인트

## 1. 유형 선택

**나열형(리스트형)** — "꼭 챙겨봐야 할 관전포인트" 구조.
선택 이유: 서머 시즌의 볼거리를 독립된 포인트로 나눠 전달하면 스크롤 소비가 쉽고, e스포츠 팬이 관심 포인트만 빠르게 캐치할 수 있다. 표지 → 포인트 8개 → 마무리(CTA)의 명확한 흐름.

## 2. 총 장수

**10장** (표지 1 + 본문 8 + 마무리 1)

## 4. 디자인 스펙 요약

- **테마**: 블랙앤화이트 에디토리얼 + e스포츠 무드
- **배경**: #0A0A0A 딥블랙 메인 / 일부 #FAFAFA 오프화이트 교차
- **포인트 컬러**: 네온 시안 `#00E5FF` (1색) — 강조 키워드/라인/페이지표시
- **폰트**: 제목 세리프(Playfair Display 류) + 본문 산세리프
- **사이즈**: 1080 × 1350px (4:5 세로형)
- **레이아웃**: 카드마다 다른 구도(풀블리드/상하분할/좌우분할), 비대칭·넉넉한 여백
- **폰트 사이즈**: 제목 ≥48px, 본문 ≥36px, 페이지번호 ≥28px (모바일 가독성 규칙 준수)
- **페이지 표시**: 하단 중앙 "03 / 10" 형식
- **이미지**: API 키 미설정 → **이미지 자리는 네온 그라디언트 플레이스홀더**로 대체 (텍스트 온리 진행)
