## Summary

홈화면에 LCK 경기 및 선수 관련 최신 유튜브 쇼츠/하이라이트 콘텐츠를 노출하는 기능을 추가한다. 현재 앱은 LCK 관련 최신 콘텐츠를 제공하지 못해 사용자가 정보 소비를 위해 유튜브 등 외부 플랫폼으로 이탈하고 있다. 이를 해결하기 위해 유튜브 채널에서 최신 영상을 수집하는 백엔드 파이프라인과, 앱 내에서 바로 재생 가능한 유튜브 임베드 플레이어를 도입하여 경기 종료 후 최대한 빠르게 관련 콘텐츠가 홈화면에 반영되도록 한다. 이를 통해 앱 체류 시간 증가와 재방문율 향상을 목표로 한다.

## Requirements

- 홈화면에 LCK 경기/선수 관련 쇼츠 콘텐츠를 최신순으로 노출하는 신규 섹션(리스트 또는 피드)을 추가해야 한다.
- 유튜브 채널(공식 채널 등)로부터 최신 영상/쇼츠 메타데이터를 주기적으로 수집하는 백엔드 파이프라인이 필요하다.
- 수집된 콘텐츠 중 "LCK 경기 또는 선수 관련" 콘텐츠만 필터링할 수 있는 기준(키워드 매칭, 채널 화이트리스트 등)이 마련되어야 한다.
- 경기 종료 시점 이후 관련 콘텐츠가 최대한 빠르게(가급적 실시간에 가깝게) 홈화면에 반영되어야 한다.
- 유튜브 임베드 플레이어를 앱 내에 구현하여 사용자가 외부 앱/웹으로 이동하지 않고 영상을 재생할 수 있어야 한다.
- 유튜브 데이터 API 쿼터 제한을 고려한 폴링 주기 및 캐싱 전략이 설계되어야 한다.
- 임베드가 제한된 영상에 대한 대체 노출 방식(예: 썸네일 + 외부 링크)을 지원해야 한다.
- 유튜브 이용약관 및 저작권 정책을 준수하는 범위 내에서 콘텐츠를 노출해야 한다.

## Design / Approach

- **콘텐츠 수집 파이프라인**: 유튜브 데이터 API를 활용해 지정된 채널(LCK 공식 채널 등)의 신규 업로드 영상을 주기적으로 폴링하는 배치/스케줄러를 구축한다. 폴링 주기는 API 쿼터 사용량과 실시간성 요구 사이의 균형을 고려하여 결정한다.
- **필터링 로직**: 채널 화이트리스트 기반 1차 필터링 후, 제목/설명/태그 등에 포함된 키워드(팀명, 선수명, "LCK" 등)를 기준으로 2차 필터링을 수행하여 관련 콘텐츠만 선별한다.
- **콘텐츠 갱신 트리거**: 경기 일정 API 연동을 통해 경기 종료 시점을 감지하고, 해당 시점 전후로 폴링 빈도를 일시적으로 높이는 방식과, 상시 주기적 폴링을 병행하는 하이브리드 방식을 검토한다.
- **데이터 저장 및 캐싱**: 수집된 콘텐츠 메타데이터(영상 ID, 제목, 썸네일, 업로드 시각, 임베드 가능 여부 등)를 서버 DB에 캐싱하여, 클라이언트 요청 시 API를 직접 호출하지 않고 캐시된 데이터를 제공한다.
- **홈화면 UI**: 신규 섹션을 홈화면 내 별도 영역(가로 스크롤 리스트 형태)으로 배치하고, 각 아이템은 썸네일과 제목을 노출하며 탭 시 인앱 임베드 플레이어로 재생되도록 한다.
- **임베드 플레이어**: 유튜브 IFrame Player API 또는 각 플랫폼(iOS/Android)의 유튜브 임베드 SDK를 활용하여 인앱 재생 컴포넌트를 구현한다. 임베드 불가 영상은 목록에서 제외하거나 썸네일 클릭 시 외부 링크로 연결되는 폴백을 적용한다.
- **쿼터 초과 대응**: API 쿼터 초과 시 마지막으로 캐싱된 데이터를 계속 제공하고, 쿼터 리셋 이후 정상 폴링을 재개하는 폴백 로직을 둔다.

## Decisions

- 콘텐츠 소비 트렌드상 "최신 경기 기준" 콘텐츠 수요가 가장 높으므로, 최신순 정렬을 1차 정렬 기준으로 채택한다.
- 외부 플랫폼 이탈을 최소화하기 위해 단순 링크 연결이 아닌 유튜브 임베드 방식을 우선 채택한다.
- 콘텐츠 수집은 크롤링이 아닌 유튜브 데이터 API 기반으로 구현하여 안정성과 정책 준수를 확보한다.
- 완전한 실시간 반영은 콘텐츠 제작 주체(방송사/구단)의 업로드 시점에 의존적이므로, "최대한 빠른 반영"을 목표로 하되 100% 실시간을 보장하지 않는다.

## Out of scope

- 유튜브 영상 자체의 편집, 재가공 또는 자체 하이라이트 클립 제작
- 선수 개인 채널/커뮤니티 채널 콘텐츠까지의 전면 확장 (별도 논의 필요, 본 스펙은 우선 공식 채널 중심으로 범위 설정)
- 유튜브 외 타 플랫폼(트위치, 아프리카TV/숲 등) 콘텐츠 연동
- 콘텐츠에 대한 댓글, 좋아요 등 소셜 인터랙션 기능 추가
- 부적절 콘텐츠에 대한 자동 신고/제재 시스템 구축

## Open questions

- 콘텐츠 수집 대상은 LCK 공식 채널만인지, 아니면 선수 개인 채널/커뮤니티 채널까지 포함하는지?
- "최신기준" 정렬 시 업로드 시간만 고려하는지, 조회수/인기도 등 추가 가중치를 반영하는지?
- 경기 종료 감지 방식은 경기 일정 API 연동, 수동 트리거, 유튜브 신규 업로드 감지 중 무엇으로 할 것인지?
- 콘텐츠 갱신(폴링) 주기는 구체적으로 몇 분 단위로 설정할 것인지?
- 임베드가 제한된 영상에 대한 대체 노출 방식(썸네일 + 외부 링크 등)의 구
