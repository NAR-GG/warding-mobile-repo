## Problem

- 홈화면에 LCK 관련 최신 콘텐츠(경기 하이라이트, 선수 쇼츠)가 제공되지 않아 사용자가 최신 정보를 앱 내에서 소비할 수 없음
- 사용자들은 최근 경기 기준으로 콘텐츠를 가장 많이 소비하는데, 현재는 이를 실시간에 가깝게 반영하지 못함
- 경기 종료 직후 관련 쇼츠/영상이 신속하게 노출되지 않아 사용자 이탈 및 외부 플랫폼(유튜브) 의존도가 높아짐
- 콘텐츠 시청을 위해 유튜브 앱/웹으로 이동해야 하는 불편함이 존재하여 앱 체류 시간이 저하됨

## Proposed outcome

- 홈화면에 LCK 경기 또는 선수 관련 쇼츠 콘텐츠를 최신순으로 노출
- 경기 종료 후 최대한 빠른 시점(가급적 실시간에 가깝게)에 관련 콘텐츠가 홈화면에 반영됨
- 유튜브 임베드 기능을 활용하여 사용자가 앱 내에서 바로 영상을 재생할 수 있도록 구현
- 사용자가 외부 유튜브 채널/앱으로 이탈하지 않고 앱 내에서 콘텐츠 소비를 완료할 수 있음
- 결과적으로 앱 체류 시간 증가 및 사용자 재방문율 향상

## Affected users and systems

- 최종 사용자: 홈화면 진입 시 최신 LCK 콘텐츠를 소비하는 전체 앱 사용자
- 홈화면 UI/UX: 신규 콘텐츠 섹션(쇼츠 리스트/피드) 추가 필요
- 콘텐츠 수집 시스템: 유튜브 채널(LCK 공식 또는 관련 채널)에서 최신 영상/쇼츠를 크롤링 또는 API로 가져오는 백엔드 파이프라인
- 유튜브 API 연동 모듈: 최신 영상 조회, 임베드 재생을 위한 API 연동 부분
- 영상 임베드 플레이어: 앱 내 유튜브 임베드 플레이어 컴포넌트 신규 개발 또는 기존 컴포넌트 확장
- 콘텐츠 갱신 스케줄러/트리거: 경기 종료 시점을 감지하거나 주기적으로 콘텐츠를 갱신하는 배치/이벤트 시스템

## Constraints

- 유튜브 데이터 API의 쿼터(할당량) 제한으로 인해 실시간에 가까운 빈번한 폴링에 제약이 있을 수 있음
- 경기 종료 시점과 실제 쇼츠/하이라이트 영상 업로드 시점 사이에 시간차가 존재할 수 있어, 완전한 실시간 반영은 콘텐츠 제작 주체(방송사/구단/개인 크리에이터)에 의존적임
- 유튜브 임베드 정책상 일부 영상은 임베드가 제한되어 있을 수 있음(업로더 설정에 따라 임베드 비활성화 가능)
- 앱 내 임베드 재생 시 유튜브 이용약관 및 저작권 정책 준수 필요
- 특정 채널/영상을 "LCK 경기 또는 선수 관련"으로 필터링하기 위한 명확한 기준(키워드, 채널 화이트리스트 등) 정의 필요
- 네트워크 환경에 따라 임베드 영상 로딩 속도 및 재생 품질에 영향 가능

## Open questions

- 콘텐츠 수집 대상은 LCK 공식 채널만인지, 아니면 선수 개인 채널/커뮤니티 채널까지 포함하는지?
- "최신기준"의 정렬 기준은 업로드 시간인지, 조회수/인기도를 함께 고려하는지?
- 경기 종료를 감지하는 방식은 무엇인지(경기 일정 API 연동, 수동 트리거, 유튜브 신규 업로드 감지 등)?
- 콘텐츠 갱신 주기는 어느 정도로 설정할 것인지(예: 5분, 10분 단위 폴링)?
- 임베드가 제한된 영상의 경우 대체 노출 방식(썸네일 + 외부 링크 등)을 제공할 것인지?
- 홈화면에 노출할 쇼츠 개수 및 UI 레이아웃(가로 스크롤, 그리드 등)은 어떻게 할 것인지?
- 유튜브 API 쿼터 초과 시 대응 방안(캐싱 전략, 폴백 로직)은 무엇인지?
- 부적절하거나 저작권 문제가 있는 콘텐츠에 대한 필터링/신고 프로세스가 필요한지?
