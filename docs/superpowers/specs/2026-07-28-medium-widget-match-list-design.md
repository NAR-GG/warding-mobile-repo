# 미디움(중형) 위젯 오늘 경기 리스트 표시 규칙 변경 설계

## 배경

Android 미디움 위젯(`schedule_widget`, `ScheduleWidgetProvider`)은 왼쪽에 오늘 경기 리스트를, 오른쪽에 미니 캘린더를 보여준다. Figma 라이트/다크 스펙 대조 결과 지난 경기 취소선, 다음 예정 경기 브랜드 그라데이션, 그 외 예정 경기 기본 검/흰 텍스트, 다크/라이트 색상 분기는 이미 코드와 정확히 일치한다.

다만 매치 리스트를 몇 개까지 실제로 보여주고 나머지를 "+N"으로 합칠지 결정하는 **선택 로직**이 현재는 배열 순서대로 앞 3개를 단순히 자르는 방식이라, 다음 두 가지가 요구사항과 다르다.

1. 지난 경기가 여러 개여도 개수 제한 없이 그대로 앞쪽에 노출된다 (원하는 동작: 최대 1개만 노출).
2. "+N" 표시 기준이 매치 4개 이상일 때였는데, 매치 3개 이상일 때로 바꿔야 한다 (= 실제 카드는 최대 2개까지만 보여주고 3번째 매치부터 "+N"으로 합산).

## 범위

- **대상**: Android 미디움 위젯(`ScheduleWidgetProvider.kt`)의 `updateWidget()` 내 매치 리스트 렌더링 블록만.
- **대상 아님**: 레이아웃 XML(`schedule_widget.xml`, `match_row.xml`), 미니 캘린더(`ScheduleWidgetService.kt`/`schedule_widget_row.xml`), 다크/라이트 색상 분기 로직, 라지/스몰 위젯, iOS 위젯. 전부 현재 상태 유지.

## 매치 선택 로직

현재 매치 배열(`todayData.matches`, `TodayMatchInfo(time, status, display)`)을 아래 순서로 처리한다.

1. **정렬**: `time` 문자열(`"HH:mm"`) 기준 오름차순 정렬. Dart 쪽에서 리그별로 개별 fetch 후 합치기 때문에 항상 시간순이 보장되지 않아, 네이티브 쪽에서 방어적으로 한 번 더 정렬한다.
2. **분리**: `status`가 `FINISHED`/`COMPLETED`인 것을 `finished`로, 그 외(`LIVE`/`IN_PROGRESS` 및 미시작)를 `upcoming`으로 분리한다. 각각 정렬 순서를 유지한다.
3. **지난 경기 선택**: `finished`가 비어있지 않으면 **가장 최근에 끝난 1개**(정렬된 `finished`의 마지막 원소)만 선택한다. 그 외 지난 경기는 노출하지 않고 "+N" 합산 대상이 된다.
4. **남은 슬롯 계산**: `remainingSlots = 2 - (지난 경기 선택됨 ? 1 : 0)` (실제 카드 최대 2개 규칙).
5. **예정 경기 채우기**: `upcoming`에서 앞에서부터 `remainingSlots`개를 선택한다.
   - 선택된 예정 경기 중 **첫 번째 항목**(시간상 가장 이른 것 = 바로 다음 예정 경기, 혹은 진행중이면 그 경기)에 브랜드 그라데이션 근사 색(`#E87558`/`#C865C9`)을 적용한다.
   - 두 번째 항목(지난 경기가 없어 `remainingSlots=2`일 때만 존재 가능)은 기본 검/흰 텍스트.
6. **오버플로우 계산**: `표시된 개수 = (지난 경기 선택 0 또는 1) + 선택된 예정 경기 수`. `overflow = 전체 matches.size - 표시된 개수`. `overflow > 0`이면 기존과 동일한 형식의 "+N" 행을 마지막에 추가한다 (지난 경기 중 노출되지 못한 것 + 슬롯을 넘긴 예정 경기가 합산됨).
7. `matches`가 원래 비어있으면 기존과 동일하게 "경기 없음" 표시를 유지한다.

### 스타일 매핑 (변경 없음)

| 역할 | 스타일 |
|---|---|
| 지난 경기 (최대 1개) | 취소선(`STRIKE_THRU_TEXT_FLAG`) + 행 전체 alpha 0.6 + 기본 텍스트색(다크 흰색/라이트 `#101113`) |
| 바로 다음 예정 경기 (선택된 예정 경기 중 첫 번째) | 그라데이션 근사 색 `#E87558`(시간)/`#C865C9`(대진), 다크·라이트 동일 |
| 그 외 예정 경기 | 기본 텍스트색(다크 흰색/라이트 `#101113`) |
| "+N" 행 | 기본 텍스트색, 기존과 동일 형식 |

### 예시로 검증

- 지난 경기 1 + 예정 경기 2 (총 3개, Figma 참고 예시): 지난 경기 1줄 + 예정 경기 중 첫 번째(브랜드색) 1줄 = 2줄만 실제 표시, 나머지 예정 경기 1개는 "+1"로 합산.
- 지난 경기 0 + 예정 경기 2 (총 2개): 슬롯 2개 모두 예정 경기로 채워짐 (첫 번째 브랜드색 + 두 번째 기본색), "+N" 없음.
- 지난 경기 2 + 예정 경기 1 (총 3개): 지난 경기는 가장 최근 것 1개만 표시, 남은 슬롯 1개는 예정 경기(브랜드색)로 채움. 나머지 지난 경기 1개는 "+1"로 합산.
- 매치 0개: 기존과 동일하게 "경기 없음" 표시.

## 테스트 계획

- Android 에뮬레이터/실기기에서 `flutter run` 후 미디움 위젯을 홈 화면에 배치.
- `HomeWidgetPreferences`의 `today_matches`를 다양한 조합(지난 경기 0/1/2개 + 예정 경기 0/1/2/3개)으로 채워 위 예시 4가지 케이스가 실제로 맞게 렌더링되는지 확인.
- 다크 모드/라이트 모드 전환 후 지난 경기 취소선 색상, 그라데이션 근사 색, 기본 텍스트 색이 Figma 스펙과 일치하는지 육안 확인.
- 경기 없음(0개) 케이스가 기존과 동일하게 동작하는지 확인.
