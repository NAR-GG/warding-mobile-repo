# Warding 계정 삭제 안내

Warding 계정은 앱 안에서 직접 삭제할 수 있습니다. 별도의 문의나 서류 없이 즉시 처리됩니다.

## 삭제 방법

1. Warding 앱 실행 → **마이페이지**
2. **설정 → 회원탈퇴** 선택
3. 안내 확인 후 탈퇴 확정

앱을 삭제해도 계정은 남습니다. 계정을 없애려면 반드시 위 절차로 탈퇴해야 합니다.
앱에 접근할 수 없는 경우 {문의 이메일 또는 구글폼 링크}로 요청하면 본인 확인 후
처리해 드립니다.

## 삭제되는 정보 (즉시)

- 소셜 계정 연결 정보, 이메일, 닉네임, 프로필 이미지
- 기기 푸시 토큰, 알림·구독 설정, 응원팀 정보
- 선수 평점 기록
- 차단 목록

## 삭제되지 않고 남는 정보

- **커뮤니티에 작성한 글과 댓글** — 삭제되지 않으며, 작성자 정보가 분리(비식별화)되어
  **"탈퇴한 사용자"** 명의로 표시됩니다. 다른 이용자의 댓글 등 대화 맥락을 보호하기 위한
  조치입니다. **남기고 싶지 않은 글·댓글은 탈퇴 전에 직접 삭제해 주세요.**
- 신고·제재 처리 기록 — 분쟁 대응과 법령상 의무 이행을 위해 보존됩니다.
- 법령이 보존을 요구하는 기록(접속 기록 등)은 해당 법령이 정한 기간 동안 보존 후
  파기됩니다.
- 데이터베이스 백업본에 포함된 정보는 백업 보관 주기에 따라 순차적으로 파기됩니다.

## 처리 기간

- 탈퇴 확정 즉시 계정과 개인정보가 삭제됩니다.
- 백업본 등 부수 사본은 보관 주기 경과 시 자동 파기됩니다.

## 재가입

탈퇴 후 같은 소셜 계정으로 다시 가입할 수 있습니다. 다만 이전 계정의 데이터(평점, 구독,
스크랩 등)는 복구되지 않으며, 제재 이력이 있는 경우 재가입 후에도 이용 제한이 적용될 수
있습니다.
